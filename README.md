# PCC_DecisionProject
Repo for code used in Electrophysiological dissociation of human posterior cingulate cortex contributions to value- and memory-based decision-making


# Ephys Data
Electrophysiological data files (for macro electrode and microwire recordings) used to generate stats/figures is too large to include on github, so can be found here: <https://upenn.box.com/s/9kiynq2ssiugz72arwq46p4zyzolxzeo>. I have uploaded post-preprocessed data that went into stats/figures.

- Behavioral data is in this repo under data/behavior

# Organization
Code is arranged by the figure that the data/stats are associated with. I am currently still organizing this data/repo, but will try to make this as easy and useful to run as possible as I have time to clean things up.
